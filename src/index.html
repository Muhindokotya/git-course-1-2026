Understanding Git Tags

A simple explanation of tags in Git.

What is a Git Tag?

A Git tag is a reference that points to a specific commit. Tags are commonly used to mark release versions such as v1.0.0.

Basic Commands

Create a Lightweight Tag

git tag v1.0.0

Create an Annotated Tag

git tag -a v1.0.0 -m "First release"

List Tags

git tag

Push Tags to Remote

git push origin v1.0.0

Push All Tags

git push --tags
